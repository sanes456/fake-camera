# Fake Camera (Android)

<p align="center">
  <img src="docs/icon.png" width="140" alt="Fake Camera icon">
</p>

Приложение для Android, которое показывает выбранное фото или видео на весь экран, чтобы использовать его вместо камеры в видеозвонках — **без root, без Xposed и без системных патчей**.

Демонстрация экрана работает в Telegram, WhatsApp, Zoom, Google Meet, Discord и других приложениях, где есть шаринг экрана.

## Как это работает

Android не разрешает обычным приложениям подменять системную камеру. Поэтому Fake Camera использует другой подход:

1. Вы выбираете фото или видео.
2. Приложение открывает его на весь экран без интерфейса.
3. В видеозвонке вы включаете «Демонстрацию экрана» и показываете этот экран.
4. Собеседники видят ваше фото или видео вместо камеры.

На Android 14+ в некоторых приложениях можно делиться не всем экраном, а одним приложением — тогда выбирайте Fake Camera.

## Возможности

- выбор фото или видео из памяти устройства;
- предпросмотр перед запуском;
- полноэкранный показ без панелей и кнопок;
- зацикливание видео;
- режимы «Заполнить» (обрезка краёв) и «Вписать»;
- отключение звука видео (по умолчанию выключен);
- экран не гаснет во время показа;
- файл запоминается между запусками;
- нет доступа к интернету, камере и микрофону;
- нет разрешений в манифесте.

## Установка

### Вариант 1. Готовая сборка

1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний успешный запуск **Build APK**.
3. Скачайте артефакт **FakeCamera-debug-apk**.
4. Распакуйте и установите `FakeCamera-debug.apk` на телефон (разрешите установку из неизвестных источников).

При пуше тега вида `v1.0.0` APK автоматически прикрепляется к GitHub Release.

### Вариант 2. Сборка в Android Studio

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3. Командная строка

```bash
./gradlew assembleDebug
```

Нужен JDK 17 и Android SDK 35.

## Использование

1. Запустите Fake Camera.
2. Нажмите **Фото** или **Видео** и выберите файл.
3. Нажмите **На весь экран**.
4. Начните видеозвонок и включите демонстрацию экрана.
5. Откройте Fake Camera. Чтобы выйти — коснитесь экрана и нажмите крестик.

Кнопки в полноэкранном режиме скрываются автоматически через 4 секунды.

## Ограничения

- Это **не виртуальная камера**. Приложения, которые запрашивают только камеру и не поддерживают шаринг экрана, не смогут показать выбранный файл.
- Системная подмена камеры на Android без root технически невозможна.
- Во время показа приложение должно быть открыто на экране.
- Звук видео по умолчанию отключён, чтобы не создавать эхо в звонке. Его можно включить кнопкой в полноэкранном режиме.

## Приватность

Приложение не имеет разрешений и не использует сеть. Выбранные файлы никуда не отправляются и не копируются — приложение получает доступ к ним через системный выбор файлов (Storage Access Framework).

## Структура проекта

```
app/src/main/java/com/fakecamera/app/
├── MainActivity.kt      выбор файла, предпросмотр, настройки
└── PlayerActivity.kt    полноэкранный показ фото/видео
```

Стек: Kotlin, AndroidX, Material 3, Media3 ExoPlayer, minSdk 23, targetSdk 35.

## Сборка

Требования: JDK 17, Android SDK Platform 35, Build Tools 35.

```bash
./gradlew assembleDebug
```

CI собирает APK автоматически через GitHub Actions (`.github/workflows/build.yml`).
