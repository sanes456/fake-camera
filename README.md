# Fake Camera (Android)

<p align="center">
  <img src="docs/icon.png" width="140" alt="Fake Camera icon">
</p>

Приложение для Android, которое показывает выбранное фото или видео на весь экран или в плавающем окне поверх других приложений, чтобы использовать его вместо камеры в видеозвонках — **без root, без Xposed и без системных патчей**.

Демонстрация экрана работает в Telegram, WhatsApp, Zoom, Google Meet, Discord и других приложениях, где есть шаринг экрана.

## Как это работает

Android не разрешает обычным приложениям подменять системную камеру. Поэтому Fake Camera использует другой подход:

1. Вы выбираете фото или видео.
2. Приложение открывает его на весь экран без интерфейса.
3. В видеозвонке вы включаете «Демонстрацию экрана» и показываете этот экран.
4. Собеседники видят ваше фото или видео вместо камеры.

Если нужно пользоваться телефоном во время показа, нажмите **«Окно поверх»**: приложение свернётся, а фото или видео останется плавающим окном поверх звонка и других приложений. Окно можно перетаскивать, менять его размер и разворачивать на весь экран. Демонстрация экрана при этом должна быть включена — приложение не подменяет камеру.

Если телефон не разрешает «Поверх других приложений», нажмите **«PiP-окно»** — фото или видео свернётся в системное окно «картинка в картинке», которому это разрешение не нужно. На Android 12+ можно также нажать Home в полноэкранном режиме: окно само перейдёт в PiP.

На Android 14+ в некоторых приложениях можно делиться не всем экраном, а одним приложением — тогда выбирайте Fake Camera.

## Возможности

- выбор фото или видео из памяти устройства;
- предпросмотр перед запуском;
- полноэкранный показ без панелей и кнопок;
- режим **«Окно поверх»**: демонстрация остаётся на экране, даже когда приложение свёрнуто;
- режим **PiP** (картинка в картинке) — работает без разрешения «Поверх других приложений»;
- перетаскивание окна, изменение размера и разворот на весь экран;
- зацикливание видео;
- режимы «Заполнить» (обрезка краёв) и «Вписать»;
- отключение звука видео (по умолчанию выключен);
- экран не гаснет во время показа;
- уведомление с кнопкой остановки;
- файл запоминается между запусками;
- нет доступа к интернету, камере и микрофону;
- разрешение «Поверх других приложений» запрашивается только для режима окна.

## Установка

### Вариант 1. Готовая сборка

1. Откройте вкладку **Actions** в репозитории.
2. Выберите последний успешный запуск **Build APK**.
3. Скачайте артефакт **FakeCamera-debug-apk**.
4. Распакуйте и установите `FakeCamera-debug.apk` на телефон (разрешите установку из неизвестных источников).

При пуше тега вида `v1.0.0` APK автоматически прикрепляется к GitHub Release.

### Вариант 2. Сборка в Android Studio

1. Откройте папку проекта в Android Studio.
2. Дождитесь синхронизации Gradle.
3. `Build → Build Bundle(s) / APK(s) → Build APK(s)`.

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 3. Командная строка

```bash
./gradlew assembleDebug
```

Нужен JDK 17 и Android SDK 35.

## Использование

1. Запустите Fake Camera.
2. Нажмите **Фото** или **Видео** и выберите файл.
3. Нажмите **На весь экран** — для обычной демонстрации экрана.
4. Либо нажмите **Окно поверх** и разрешите показ поверх других приложений (на Android 13+ ещё и уведомления). Приложение свернётся, а окно с фото или видео останется на экране.
5. Если разрешение «Поверх других приложений» недоступно, нажмите **PiP-окно** — откроется системное окно «картинка в картинке». Его можно перетаскивать и разворачивать средствами системы.
6. Откройте приложение звонка и включите демонстрацию экрана. Окно будет видно поверх звонка.
7. В окне: потяните за ручку слева вверху, чтобы переместить; потяните за круглый угол, чтобы изменить размер; кнопка с квадратом разворачивает на весь экран; крестик останавливает показ.

В полноэкранном режиме кнопки скрываются автоматически через 4 секунды — коснитесь экрана, чтобы показать их. Кнопка «Назад» в полноэкранном оверлее возвращает к плавающему окну. Кнопка PiP на верхней панели полноэкранного режима сворачивает показ в «картинку в картинке».

## Ограничения

- Это **не виртуальная камера**. Приложения, которые запрашивают только камеру и не поддерживают шаринг экрана, не смогут показать выбранный файл.
- Системная подмена камеры на Android без root технически невозможна.
- Демонстрация экрана показывает то, что реально на экране. Режим «Окно поверх» решает это: окно остаётся при свёрнутом приложении. В режиме окна оно занимает часть экрана, а в полноэкранном режиме перекрывает интерфейс звонка — нажмите «Назад» или кнопку-квадрат, чтобы вернуться к окну.
- Во время показа приложение должно быть запущено, а демонстрация экрана — включена.
- На некоторых прошивках (MIUI, ColorOS и т.п.) нужно дополнительно разрешить «Поверх других приложений» и отключить оптимизацию батареи, иначе система может остановить окно.
- PiP зависит от прошивки: на устройствах без поддержки «картинки в картинке» остаётся обычная демонстрация экрана, разделённый экран или второй телефон/экран.
- Звук видео по умолчанию отключён, чтобы не создавать эхо в звонке. Его можно включить кнопкой в окне или полноэкранном режиме.

## Приватность

Приложение не запрашивает камеру, микрофон и доступ в интернет. Для режима «Окно поверх» Android требует разрешение «Поверх других приложений», а для уведомления о работе окна на Android 13+ — разрешение на уведомления. Выбранные файлы никуда не отправляются и не копируются — приложение получает доступ к ним через системный выбор файлов (Storage Access Framework).

## Структура проекта

```
app/src/main/java/com/fakecamera/app/
├── MainActivity.kt      выбор файла, предпросмотр, настройки
├── PlayerActivity.kt    полноэкранный показ фото/видео и PiP
├── OverlayService.kt    плавающее окно поверх других приложений
└── ImageLoader.kt       загрузка и поворот фото
```

Стек: Kotlin, AndroidX, Material 3, Media3 ExoPlayer, minSdk 23, targetSdk 35.

## Сборка

Требования: JDK 17, Android SDK Platform 35, Build Tools 35.

```bash
./gradlew assembleDebug
```

CI собирает APK автоматически через GitHub Actions (`.github/workflows/build.yml`).
